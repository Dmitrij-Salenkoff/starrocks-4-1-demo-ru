# Демоурок · StarRocks 4.1

Изучите два способа хранить одни и те же чеки, сравните PostgreSQL, DuckDB, ClickHouse, BigQuery и StarRocks, затем проследите путь одного запроса. На стенде вы увидите, какой узел принимает запрос, кто читает данные и как из отдельных продаж получаются шесть чашек за день.

**Инструменты:** StarRocks 4.1.4 · Docker Compose · Python 3.14 · uv · VS Code · DataGrip.

## Пройти демоурок

[Аналитические базы и архитектура StarRocks](weeks/01/01/README.md)

Начните со слайдов или текста занятия. Когда дойдёте до практики, откройте инструкцию по подготовке рабочего места. Видео рассчитано на 38 минут, самостоятельная работа на готовом стенде — ещё на 45 минут.

В полном курсе 12 недель. От первого отчёта вы перейдёте к загрузке данных, устройству базы и разбору ситуаций, когда отчёт работает медленно или показывает устаревшие данные.
