# Демоурок · StarRocks 4.1

StarRocks — аналитическая база данных. Она помогает отвечать на вопросы сразу по многим записям. В первом уроке вы поможете владельцу кафе посчитать проданные чашки, добавите ещё один чек и увидите обновлённый ответ. Все команды и запросы уже написаны.

**Инструменты:** StarRocks 4.1.4 · Docker Compose · Python 3.14 · uv · VS Code · DataGrip.

[Подготовка рабочего места](START.md) · [Слайды демоурока (PDF)](weeks/01/01/slides.pdf)

## Пройти демоурок

[Первый запрос в StarRocks](weeks/01/01/README.md)

Откройте инструкцию к уроку выше. Она проведёт вас от установки программ до первого ответа в DataGrip. Видео рассчитано на 18 минут, самостоятельная практика — ещё на 35 минут после установки.

В полном курсе 12 недель. От первого отчёта вы перейдёте к загрузке данных, устройству базы и разбору ситуаций, когда отчёт работает медленно или показывает устаревшие данные.
