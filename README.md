# Демоурок · StarRocks 4.1

Одна покупка была доставлена дважды. Почему отчёт вырос с $33 до $45 и как доказать, какая строка лишняя? Разберите учебную выписку в настоящем StarRocks, затем проверьте свою гипотезу.

**Инструменты:** StarRocks 4.1.4 · Docker Compose · Python 3.14 · uv · VS Code · DataGrip.

[Подготовка рабочего места](START.md) · [Слайды демоурока (PDF)](weeks/01/01/slides.pdf)

## Пройти демоурок

[Почему отчёт показывает $45 вместо $33?](weeks/01/01/README.md)

После настройки запустите команды из корня репозитория. В DataGrip откройте SQL-консоль из инструкции. После разбора выполните задания в демоуроке.

```sh
uv sync --locked
uv run python lab.py up 01/01
uv run python lab.py setup 01/01
uv run python lab.py explore 01/01
uv run python lab.py check 01/01
```

Полная программа охватывает 10 недель: архитектура OLAP, модели таблиц, Stream Load и Kafka, CDC и backfill, аналитический SQL, профили и материализованные представления, Iceberg, эксплуатация, AI и выпускной проект.
