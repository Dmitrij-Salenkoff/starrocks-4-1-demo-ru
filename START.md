# Как подготовиться к первому уроку

Представьте, что у кафе накопились чеки и нужно посчитать продажи за день. Чеки учебного кафе уже подготовлены. Вы запустите StarRocks на своём компьютере, а затем откроете DataGrip — программу, через которую можно задать базе вопрос и увидеть ответ в виде таблицы.

## 1. Откройте материалы урока

Если вы на GitHub, нажмите **Code → Download ZIP** и распакуйте скачанный архив. В VS Code выберите **File → Open Folder** и откройте папку, в которой видны файл `lab.py` и каталог `weeks`. Все команды ниже вводятся в этой папке. [Скачать VS Code](https://code.visualstudio.com/)

## 2. Подготовьте программы

- **Docker с Docker Compose** запускает на компьютере готовую копию базы. На macOS и Windows установите Docker Desktop, откройте приложение и дождитесь сообщения о готовности. На Linux подойдёт Docker Engine с плагином Compose. [Установить Docker](https://docs.docker.com/get-started/get-docker/)
- **uv** устанавливает Python и программы, которыми мы запустим учебный пример. [Установить uv](https://docs.astral.sh/uv/getting-started/installation/)
- **DataGrip** понадобится для работы с данными. Установите его и откройте проект. [Скачать DataGrip](https://www.jetbrains.com/datagrip/download/)

Для первой загрузки программ и образа базы нужен интернет. После установки откройте **Terminal → New Terminal** в VS Code. Терминал — это окно, куда можно вставлять команды. Выполняйте их по одной, дожидаясь следующей строки ввода.

```sh
docker compose version
uv python install 3.14
uv sync --locked
uv run python lab.py up 01/01
uv run python lab.py setup 01/01
```

Первая команда проверяет Docker Compose. Следующие две устанавливают Python 3.14 и зависимости курса. Команда `up` запускает учебную базу. При первом запуске загрузка может занять несколько минут. Команда `setup` заполняет базу примерами чеков.

## 3. Подключите DataGrip к запущенной базе

В окне **Database Explorer** нажмите **+ → Data Source → MySQL**. StarRocks понимает этот способ подключения. Введите значения из таблицы.

| Поле в DataGrip | Что ввести |
|---|---|
| Host | `127.0.0.1` — ваш компьютер |
| Port | `9030` |
| User | `root` |
| Password | Оставьте поле пустым |
| Database | `course` |

Если программа предлагает **Download missing driver files**, нажмите эту ссылку. Затем нажмите **Test Connection** и **OK**. После успешного подключения откройте [первое занятие](weeks/01/01/README.md). В нём вы выполните готовый запрос в DataGrip и сравните результат с чеками. [Настройка подключения в DataGrip](https://www.jetbrains.com/help/datagrip/mysql.html)

## Если первый запуск остановился

| Что видно | Как продолжить |
|---|---|
| Терминал не находит `uv` или `docker` | Установите соответствующую программу, закройте терминал и откройте его заново. |
| Docker сообщает, что не может подключиться | Запустите Docker и подождите, пока он станет готов, затем повторите `up`. |
| DataGrip показывает «Connection refused» | Дождитесь завершения `up` и проверьте значения Host и Port. |
| В списке нет таблицы `cafe_sales` | Выполните `uv run python lab.py setup 01/01`, выберите базу `course` и обновите список таблиц. |
| За 3 января уже получилось 8 чашек | Вы уже добавляли новый чек. Команда `setup 01/01` восстанавливает исходный пример с 6 чашками. |

В конце практики команда `uv run python lab.py down 01/01` останавливает учебную базу и удаляет данные этого стенда. Сохраните свои заметки отдельно.
