**Длительность:** 5–6 минут. На экране терминал и редактор SQL. Перед записью откройте каталог урока, скачайте образ и держите `solution.sql` во второй вкладке. Показывайте фактические результаты команд и план на своём стенде. После каждого запроса оставьте несколько секунд для чтения.

## Команды в порядке записи

```sh
docker compose up -d --wait
uv run --project ../.. python ../../tools/lab.py setup
```

В DataGrip выберите драйвер MySQL, адрес `127.0.0.1:9030`, пользователя `root` и пустой пароль. Для работы из терминала используйте `docker compose exec starrocks mysql -uroot -h127.0.0.1 -P9030 sr01`.

```sql
USE sr01;
SHOW FRONTENDS;
SHOW BACKENDS;
SELECT event_id, event_day, order_id, event_type, amount_minor
FROM payment_events ORDER BY event_id;
SELECT event_day, SUM(amount_minor) AS candidate_net
FROM payment_events GROUP BY event_day ORDER BY event_day;
```

На отметке 2:40 выполните `solution.sql`. Эквивалент в терминале — `uv run --project ../.. python ../../tools/lab.py solve`. Затем выполните:

```sql
SELECT * FROM sr01.daily_revenue ORDER BY event_day;
EXPLAIN SELECT event_day, net_minor FROM sr01.daily_revenue
WHERE event_day = '2026-01-13';
```

```sh
uv run --project ../.. python ../../tools/lab.py check
```
